## Personal Budget Dashboard

I was tired of manually entering every transaction into my Excel budget spreadsheet. I decided to automate the entire data ingestion process and build interactive dashboards to better understand where my money goes.

This project is designed to become a complete personal financial data platform that combines ETL pipelines, SQL databases, data visualization, and machine learning to automate expense tracking, budgeting, and financial forecasting.
